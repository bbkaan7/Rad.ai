# Referans resimler

Kendi sohbet uygulamandan aldığın ekran görüntüsünü kırparak buraya koy:

- `textbox.png`: boş mesaj kutusu, kenarları ve ayırt edici görsel ayrıntıları dahil.
- `send_btn.png`: mesaj yazıldıktan sonraki etkin Gönder butonu.

Tamamen düz renkli bir alan seçme. Kırpmanın merkezi tıklanabilir alanın içinde
olsun. Ekran ölçeği, uygulama yakınlaştırması ve tema örnek alınan resimle aynı
olmalı. Bu Alpha, ölçekten bağımsız tespit yapmaz. Gerçek uygulamanın görüntüleri
olmadan doğru referans üretilemeyeceği için sahte PNG dosyaları eklenmemiştir.
